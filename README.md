# Maşın modelləri

10 Hunyuan3D maşın: 8-i Rally Kings: Open Roads, 2-si Last Exit oyunundan.

Döndürmək üçün bu səhifəni açın və ya `models/` qovluğunda istənilən `.glb` faylına klikləyin.

Loop yolları hələ yoxdur — Hunyuan limiti açılınca əlavə olunacaq.

Planlaşdırılan ünvan: https://bayramovqdir494-sys.github.io/car-loop-assets/

Forma: Tencent Hunyuan 3D 2.1. Yeni generasiya deyil, əvvəlki oyun modellərinin təkrar istifadəsidir.
